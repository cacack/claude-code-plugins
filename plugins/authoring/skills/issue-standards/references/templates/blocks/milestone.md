# Milestone block

Paste into the milestone's description field. A milestone is not an issue, so it
carries no acceptance criteria and no per-type additions — it carries a closure
condition instead.

```markdown
## At a glance

<3-5 plain-English sentences: what this body of work is and why it matters.>

## Context

**Why now:** <the trigger>
**What is missing:** <the observable gap the group closes>
**Value:** <what the group delivers, or what it costs not to do it>

## Closure condition

<What has to be true for this to close, in terms a reader can check.
Name the finite set: "every skill in authoring/ has a matching auditor",
not "the authoring work is done".>

## References

- [<design, decision record, or source>](<URL>) — <what the reader gets from it>
```
